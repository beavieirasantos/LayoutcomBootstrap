# Layout com Bootstrap 5

Projeto desenvolvido como atividade prática da disciplina de **Front-End**, com o objetivo de aplicar os conhecimentos de **Bootstrap 5** na construção de um layout para uma página web.

## Sobre o projeto

O projeto consiste na criação de uma interface utilizando **HTML5, CSS3 e Bootstrap 5**, explorando os recursos do framework para estruturar e estilizar a página.

A atividade foi desenvolvida durante as aulas de Front-End como forma de praticar a construção de layouts e a utilização de ferramentas que facilitam o desenvolvimento de interfaces responsivas.

## Tecnologias utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript

## O que foi praticado

Durante o desenvolvimento do projeto, foram utilizados conceitos como:

* Estruturação de páginas com HTML5
* Construção de layouts com Bootstrap 5
* Sistema de Grid
* Responsividade
* Classes e componentes do Bootstrap
* Organização de elementos na página
* Estilização com CSS
* Estruturação de arquivos de um projeto Front-End

## Objetivo

O objetivo desta atividade foi colocar em prática os conhecimentos adquiridos nas aulas de **Front-End**, utilizando o Bootstrap 5 como ferramenta para auxiliar na criação e organização de layouts para páginas web.
